# Security Policy

## Supported Versions

Currently, only the latest version is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.2.x  | :white_check_mark: |
| < v1.2  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in the R-32 CPU, please open an issue on GitHub with the label `security`.

Please do not disclose the vulnerability publicly until it has been addressed.
